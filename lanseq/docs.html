Base URL

https://api.lanseq.cloud/v1 is the canonical production API surface. Supported endpoints follow familiar OpenAI-compatible request semantics.

Authentication

Each approved integration receives its own bearer credential. Credentials are isolated by partner and can be limited or revoked independently.

  -H "Content-Type: application/json" \
  -d '{"model":"qwen3.8-27b-int4","messages":[{"role":"user","content":"Hello"}]}'

Streaming and tools

Qualified routes can support server-sent-event streaming, tool calling, structured responses and reasoning-oriented workloads. Integration partners can validate these capabilities directly with an isolated review credential.

Data handling

Lanseq does not use customer prompts or model outputs to train models. Operational metadata may be retained for service operation, security, abuse prevention, accounting and platform obligations.
