03 / Interface

One endpoint. Familiar semantics.

Approved integrations receive an isolated bearer credential. Credentials are never published in repositories or shared between evaluation partners.

curl https://api.lanseq.cloud/v1/chat/completions \
  -H "Authorization: Bearer $LANSEQ_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen3.8-27b-int4","messages":[{"role":"user","content":"Hello"}],"stream":true}'
