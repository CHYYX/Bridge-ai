03 / Integration

One endpoint. Familiar semantics.

Approved integrations receive an isolated bearer credential. A platform can qualify model discovery, chat, streaming and tools without adopting a proprietary SDK.

POST /v1/chat/completionscurl
curl https://api.lanseq.cloud/v1/chat/completions \
  -H "Authorization: Bearer $LANSEQ_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen3.8-27b-int4","messages":[{"role":"user","content":"Hello"}],"stream":true}'
Evaluation credentials are provisioned individually and can be revoked independently.
