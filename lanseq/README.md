# Lanseq public provider surface

Static public site for Lanseq. Designed as a minimal, infrastructure-first surface for provider reviewers and integration partners.

## Deploy

Set the deployment root directory to `lanseq/` and use a static deployment. No build command is required. `vercel.json` enables clean URLs.

## Truthfulness constraints

- Access is described as controlled, not self-service.
- The site does not claim a public uptime SLA or automated monitoring dashboard.
- Only the currently published Qwen3.8-27B INT4 route is listed as live.
- Additional models are described as demand-driven, not already live.
